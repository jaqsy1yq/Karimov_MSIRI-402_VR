## Запуск тренажёра

1. В Unity Hub добавить папку `VR_Trainer_(13.11)` и открыть её в Unity 6000.0.85f2.
2. Открыть сцену `Assets/Scenes/Тренажёр_фрезерный.unity` (она первая в Build Settings).
3. С VR-шлемом: подключить шлем, запустить SteamVR, нажать **Play**.
4. Без шлема: нажать **Play**, включится камера на уровне глаз с управлением с клавиатуры и мыши.

## Управление

**VR-шлем:** заготовку берут кнопкой захвата контроллера, кнопки пульта нажимают рукой, по цеху перемещаются телепортом по полу.

**Клавиатура и мышь:**

| Клавиша | Действие |
|---|---|
| W, A, S, D | ходьба по цеху |
| Shift | ходьба быстрее |
| правая кнопка мыши (удерживать) | поворот головы |
| левая кнопка мыши | нажать кнопку пульта, взять заготовку, положить её туда, куда указывает курсор |

Через станок, верстаки и стены пройти нельзя: камера ходит через CharacterController.

## Рабочее место

- **Фрезерный станок** из Blender, уменьшен до 0,6, чтобы стол был на высоте около 1,15 м.
  - У станка подвижные узлы: шпиндель с фрезой и рабочий стол с тисками.
- **Защитный щиток**: прозрачный экран перед тисками, опускается и поднимается кнопкой «Щиток».
- **Стол заготовок** (синяя метка) и **стол готовых деталей** (зелёная метка).
- **Пульт оператора** на стойке:
  - кнопки «Далее», «Щиток», «Пуск», «Стоп», «Заново»;
  - номер шага;
  - лампа щитка: красная – щиток поднят, зелёная – опущен.
- **Экран обучения** на стене за станком: 9 клеток шагов (пройденные зелёные, текущий оранжевый), название шага, подсказка, баллы, время и итог.
- **Экран сервера**: только чтение. Раз в 0,5 с отправляется GET-запрос `https://cnc.kovalev.team/get/3`, на экран выводятся состояние станка, координаты X, Y, Z и состояние связи.

## Порядок работы

1. **Ознакомление** – осмотреть станок и оба стола, нажать «Далее».
2. **Проверка станка** – шпиндель вверху, щиток поднят, тиски пустые; нажать «Далее».
3. **Взять заготовку** со стола заготовок.
4. **Установка в тиски** – поднести заготовку к тискам и отпустить. Она точно встаёт в тиски и закрепляется.
5. **Защитный щиток** – нажать «Щиток», щиток опускается, лампа становится зелёной.
6. **Пуск** – нажать «Пуск».
7. **Фрезерование** (8 с):
   - фреза вращается, шпиндель опускается на заготовку;
   - стол делает проход вдоль оси X туда и обратно, заготовка едет вместе с ним;
   - затем шпиндель поднимается, деталь меняет цвет на синий.
8. **Снять деталь** – поднять щиток кнопкой «Щиток», взять деталь и положить на стол готовых деталей.
9. **Итог** – время, баллы и список ошибок. Кнопка «Заново» возвращает всё в начало.

Начисление баллов: в начале 100, каждая ошибка снимает 10.

## Ошибки и запреты

| Действие | Реакция тренажёра |
|---|---|
| «Далее» после шага 2 | ошибка «Лишнее нажатие «Далее»» |
| «Пуск», когда заготовки нет в тисках или она в руке | пуск запрещён, ошибка «Пуск без заготовки» |
| «Пуск» при поднятом щитке | пуск запрещён, ошибка «Пуск с открытым щитком» |
| «Пуск» во время фрезерования | ошибка «Повторный пуск» |
| «Щиток» во время фрезерования | аварийная остановка, ошибка «Щиток открыт во время работы», возврат к шагу 5 |
| опустить щиток до установки заготовки | ошибка «Щиток закрыт не вовремя» |
| заготовка отпущена мимо тисков | ошибка «Заготовка не в тисках», её можно взять снова |
| деталь отпущена мимо стола готовых деталей | ошибка «Деталь не на столе готовых» |
| «Далее» на шаге 2 при опущенном щитке или опущенном шпинделе | переход не выполняется, подсказка |
| взять заготовку во время фрезерования или при опущенном щитке на шаге 8 | заготовка не берётся |
| «Стоп» во время фрезерования | узлы возвращаются на место, заготовка остаётся в тисках, можно снова нажать «Пуск» |
| «Заново» с заготовкой в руке | просьба сначала отпустить заготовку |

## Скрипты (`VR_Workshop/Assets/Scripts`)

| Скрипт | Назначение |
|---|---|
| `MachineTrainer` | сценарий из 9 шагов: проверки, щиток, фрезерование, баллы, ошибки, итог, сброс |
| `TrainingBlank` | заготовка вместо Throwable: берётся рукой только с разрешения сценария, ставится точно в тиски и на стол |
| `DesktopControls` | управление без шлема: ходьба, обзор, нажатие кнопок и перенос заготовки мышью |
| `MachineClient` | клиент сервера станка: GET-запрос, разбор JSON (Newtonsoft), координаты X, Y, Z |
| `MachinePanel` | вывод состояния, координат и сообщений на экран сервера |
| `MachineTelemetryClient` | первый вариант клиента сервера (занятие 11.11) |
| `MachineState` | данные станка: работает или нет, координаты X, Y, Z |
| `MachineButtonTest` | кнопки «Пуск» и «Стоп» на панели сцены 11.11 |
