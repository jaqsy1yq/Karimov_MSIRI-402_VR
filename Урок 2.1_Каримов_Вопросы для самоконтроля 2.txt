Вопросы для самопроверки

1.Зачем скрывать поля класса?

Поля класса скрывают для защиты внутреннего состояния объекта от некорректных изменений. Это реализуется с помощью инкапсуляции и модификатора private. Доступ к данным предоставляется через публичные методы и свойства, которые позволяют проверять значения и предотвращать ошибки.

2.Чем свойство отличается от поля?

Поле — это переменная внутри класса, которая непосредственно хранит данные объекта. Свойство — это механизм контролируемого доступа к этим данным. С помощью get можно читать значение, а с помощью set-изменять его. Свойство также может содержать дополнительную логику проверки данных.

3.Что произойдёт, если не объявить ни одного конструктора?

Если в классе не объявлен ни один конструктор, компилятор автоматически создаст конструктор по умолчанию без параметров. Он позволит создавать объекты с помощью оператора new. Поля объекта получат стандартные значения: например, 0 для числовых типов и null для ссылочных типов.

4.Как конструктор связан с инкапсуляцией?

Конструктор обеспечивает правильное начальное состояние объекта при его создании. Он позволяет задавать значения приватных полей, проверять входные данные и предотвращать создание объекта с некорректными значениями. Таким образом, конструктор контролирует создание объекта, а инкапсуляция защищает его внутреннее состояние.

5.Можно ли изменить свойство только для чтения после создания объекта?

Свойство только для чтения не имеет доступного метода set, поэтому изменить его напрямую извне нельзя. Например, свойство Id { get; } можно задать в конструкторе, но после создания объекта его значение изменить нельзя. Это позволяет защитить важные данные от нежелательных изменений. При этом вычисляемое свойство может возвращать изменяющееся значение внутреннего поля.
