1. Какую роль выполняет Unity в клиент-серверной схеме?

Unity выполняет роль клиента: отправляет запросы серверу, получает данные и использует их для управления 3D-объектами.

2. Какой HTTP-метод использует CncJsonController?

Используется метод GET для получения данных с сервера.

3. Как найти координату X внутри массива data?

Нужно обратиться к нужному элементу массива data по индексу и получить значение координаты X.

4. Зачем удалять «мм» и изменять запятую точкой?

Чтобы преобразовать строку в числовое значение типа float, которое Unity сможет использовать для вычислений и перемещения объектов.
