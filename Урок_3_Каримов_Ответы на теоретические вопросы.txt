1. Отличие коллайдера от коллизии

Коллайдер-компонент Unity,который определяет физические границы объекта для обнаружения столкновений.

Коллизия-событие столкновения двух объектов,имеющих коллайдеры.

2. Отличие while от do while

while-цикл,в котором условие проверяется перед выполнением. Если условие ложное,цикл не выполнится ни разу.

do while-цикл, в котором условие проверяется после выполнения. Поэтому цикл выполнится минимум один раз.

3. Методы Web-запросов

GET-получение данных с сервера.
POST-отправка данных на сервер.
PUT-полное обновление существующих данных.
PATCH-частичное обновление данных.
DELETE-удаление данных с сервера.

4. Когда используется OnCollision и OnTrigger

OnCollision-используется при физическом столкновении объектов с коллайдерами, например при столкновении автомобиля со стеной.

OnTrigger-используется, когда объект входит в специальную зону с включённым параметром Is Trigger, например для подбора предметов или активации событий.

Для работы этих событий обычно требуется наличие Rigidbody хотя бы у одного из взаимодействующих объектов.

5. Для чего нужен интерфейс Input

Input-система Unity для обработки действий пользователя с помощью клавиатуры, мыши или геймпада.

Используется для управления персонажем, автомобилем, камерой и другими игровыми объектами.

Например, Input.GetKey() проверяет нажатие клавиши, а Input.GetAxis() получает значение оси управления.
